# 所选模型的参数

先读[能力发现](capability-discovery.md)。以工具/模型配对的实时 `arguments`、`inputs`、默认值、枚举和条件约束为准，不维护静态模型表。

## 请求与输出

- 模型声明的参数与输入是允许列表：满足必填项和依赖，省略未声明或无关字段。无媒体时按工具 schema 决定是否省略 `inputs`。
- 参数名不得重复；数字、布尔、JSON 数组按工具要求编码，枚举使用精确值。切换模型时重建请求，不沿用旧模型字段。
- 用户设置优先，默认质量仅用于合法且兼容的选项。不能用提示词模拟不支持的分辨率、素材或音频能力。
- 首帧比例遵循实时规则：要求省略且用户未指定时省略；存在比例字段时选择投放目标或兼容默认值。纯文本不支持自动比例时显式选择合法比例；无字段时不发明替代名称。
- 时长须容纳动作、对白、停顿与结尾。不得删对白、加速或拆成多项付费任务掩盖冲突。
- 尊重内容边界：只有模型声明且支持时，使用 `imageCount`、`prefer_multi_shots`、`enable_audio`、`enable_asmr` 控制单结果、连续镜头及静音，不增加用户未要求的音效或多镜头。
- `prefer_multi_shots` 若只允许 `true`，不得传 `false`；省略是否有效取决于默认值。该字段描述智能分镜，不保证每次多镜头；省略或换入口也不保证单镜头。连续镜头提示词仅表达意图，不能声称结果保证。

## 参考素材与主体

主体库与上传遵循[素材流程](asset-workflows.md)。

- 把每份真实素材映射至声明的输入槽和提示词引用；区分首尾帧、身份/商品、风格、动作和编辑源。使用所选模型自己的绑定语法。
- 关键帧保持顺序并描述过渡；不发明中间帧槽、时间戳或数量公式。首帧不锁定所有后续运动。
- 按实时要求检查来源、格式、大小、尺寸及单项/总时长。能读元数据时检查真实值，不能仅凭文件名声称验证。不因上传失败或超限静默删素材。
- 复用前调用 `element_get` 检查真实资源类型。模型必须同时声明绑定参数和该类型支持。检查 `elementSupport` 的图片/视频、单项/总数量以及参考视频存在时的限制。主体库容量不等于一次生成的参考上限；视频主体封面不能代替视频，Element 不能代替必填图片。
- 检查 `maxItems`、`combinedItemCap`；对每项 `combinedItemCaps[]`，按真实输入计算 `whenAnyInputPrefixes` 与 `whenNoneInputPrefixes`，满足所有生效上限。按实际素材数计数，不按最大槽编号计数，Element 按声明计入。
- 动作控制仍要求主体图片及唯一动作源。预览链接不是动作 ID。

## 音频

- 区分生成声音、保留源视频原声、静音、对白和旁白；只用声明的控制字段。工具级描述不能证明每个模型支持音频。
- `enable_audio` 与 `keepOriginalSound` 声明互斥时不能同时启用，未声明则不传。用户要求冲突时说明限制，不能只在提示词掩盖。
- 音频参考只使用声明的槽位、格式、时长和引用语法，不能塞入图片或视频槽；接受音频不代表支持声音克隆或逐字复现。
- 原样保留用户对白的说话人、语言、语气与顺序。旁白不等于画面内对白，对白不授权添加字幕或标语。
- 提交前对齐实际参数、时长和音频意图。只有检查真实音轨后才能声称音频验收完成，封面或静音预览不足以证明。
